# Dashboard Components

Reusable components developed for the CogniStream dashboard.

## Components

### Sidebar.jsx
Provides dashboard navigation.

### Header.jsx
Displays the dashboard title and preview status.

### KPICard.jsx
Reusable card for displaying developer analytics metrics.
