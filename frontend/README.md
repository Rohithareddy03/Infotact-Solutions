# CogniStream Frontend

## Overview

The CogniStream frontend is a React-based dashboard for visualizing developer activity and flow-state indicators.

## Technologies

- React
- Vite
- Tremor
- JavaScript
- CSS
- Lucide React

## Planned Features

- Developer analytics dashboard
- KPI cards
- Developer activity charts
- Flow-state duration visualization
- Context-switching analysis
- Interruption timeline
- Date and developer filters

## Run the Application

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
