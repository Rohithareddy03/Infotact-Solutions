# CogniStream Dashboard Requirements

## 1. Project Objective

Build a React dashboard to visualize developer activity and observable indicators related to uninterrupted work, context switching, and interruptions.

## 2. Technology Stack

- React
- Vite
- Tremor
- JavaScript
- CSS
- FastAPI (backend integration)

## 3. KPI Cards

The dashboard will display:

- Total Commits
- IDE Activity Time
- Average Session Duration
- Number of Coding Sessions
- Context Switch Count
- Potential Interruption Count

## 4. Planned Visualizations

- Developer Activity Overview
- Flow-State Duration Chart
- Context-Switching Chart
- Interruption Timeline
- Daily Activity Trends

## 5. Filters

- Date range
- Developer
- Activity source

## 6. Data Source

The dashboard will receive processed analytics from the FastAPI backend.

## 7. Important Note

The dashboard will display activity-based estimates. It will not claim to directly measure a developer's actual cognitive state.
